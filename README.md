# Shonen Eveil - update repository

Generated by the pack tooling. Read by the pack's updater program ("Mettre a jour Shonen Eveil"); not meant to be edited by hand.

- `index.json`: pack version, and for each file its path, size, sha256 and where it comes from.
- `files/`: the files served from this repository (ours, or under a licence that allows redistribution).
- Other mods are downloaded by the updater from their authors' own pages (checked by sha256).
